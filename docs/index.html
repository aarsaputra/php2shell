php2shell v1.5.1

Unauthenticated RCE chain for PHP 5.4 → 8.4.26 — pure-HTTP, JA3 impersonation, proof-of-access by design.
CVE 2026-109619 CVE 2026-109618 (deteksi) fix-floor 8.2.35 / 8.3.36 / 8.4.27 / 8.5.12 tests 118 passed ⭐ 47 · 🍴 32
GitHub repo Tutorial (semua fitur) Runbook RCE → up-shell

Apa ini

Rantai 3-tahap penuh-HTTP: heap leak → libphp base leak → HashTable palsu → zif_system (CVE-2026-109619, stale global state antar-request pada worker yang sama). Tanpa file, tanpa endpoint khusus, tanpa crypto di sisi klien — hanya multipart POST.

detect

Versi PHP, SAPI, upload_progress, display_errors — read-only; OOM probe otomatis bila versi tak bocor.

preflight

Skor kesiapan 0–90 + BLOCKER eksplisit sebelum exploit.

exploit

RCE terbukti dengan bukti (--proof-file: uid=33(www-data)), carrier 14 byte, whitelist perintah.

shell & up-shell

Generator webshell (bcrypt, TTL, audit) + pemasangan otomatis lewat RCE (dua jalur, verifikasi per-karakter).

Quickstart

# pasang (venv + deps + smoke)
git clone https://github.com/aarsaputra/php2shell && cd php2shell
./install.sh && source .venv/bin/activate

# kenali target (read-only)
python php2shell.py detect -u http://target-lab/

# bukti RCE — berhenti di sini untuk bug bounty
python php2shell.py exploit -u http://target-lab/ --yes --proof-file p1
# PROOF (11.7s): uid=33(www-data) gid=33(www-data)

Dukungan build (data terukur)

  • RCE terbukti (5): 8.4.26 amd64 (profil bookworm), 8.5.11 amd64/aarch64, 8.5.10 aarch64, 8.4.25 aarch64*
  • Leak saja (3): 8.5.0, 8.3.35, 8.3.33 — stage-3 belum jalan
  • Belum terbukti (5): 8.3.0, 8.2.34, 8.1.34, 8.0.30, 7.4.33 — UAF ada, bentuk leak beda

* probabilistik, butuh retry. Detail: RUNBOOK §0.

Etika: hanya untuk sistem milik sendiri / otorisasi tertulis. Bug bounty: hampir semua RoE melarang webshell tertinggal — cukup bukti RCE (--proof-file), berhenti di situ. Status BLIND/HEAP_LEAK_FAILED = hasil pengukuran tool (perintah tidak dieksekusi / tak ada kanal bukti), bukan bug.
